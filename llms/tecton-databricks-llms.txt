# Tecton (Databricks)

> Tecton is a feature platform / feature store for machine learning and AI. It lets teams define, transform, materialize, and serve features from batch, streaming, and real-time data sources, with a low-latency online store served over an HTTP Feature Service API and a Python SDK. Tecton was acquired by Databricks in August 2025. This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface (docs.tecton.ai) — the provider does not publish its own /llms.txt.

## APIs
- [HTTP API Reference (Feature Serving, Ingest, Metadata, SCIM)](https://docs.tecton.ai/http-api): REST API; auth via `Authorization: Tecton-key <API-KEY>` or Service-Account OAuth. Example: `POST /api/v1/feature-service/get-features`.

## SDKs and clients
- [Tecton Python SDK (pip install tecton)](https://pypi.org/project/tecton/): define/test/manage features; bundles the `tecton` CLI.
- [Tecton Python HTTP client (pip install tecton-client)](https://pypi.org/project/tecton-client/): low-latency online feature retrieval.
- [Tecton Java client](https://github.com/tecton-ai/tecton-http-client-java): Online Store Java client.
- [Airflow provider (airflow-provider-tecton)](https://pypi.org/project/airflow-provider-tecton/): orchestrate materialization.
- [Terraform provider (tecton-ai/tecton)](https://registry.terraform.io/providers/tecton-ai/tecton): infrastructure-as-code.

## Agents
- [Tecton MCP server](https://github.com/tecton-ai/tecton-mcp): official Model Context Protocol server (stdio); docs/SDK/metrics tools.
